# 文档归档区

本目录保存项目文档在**大改版前的整份快照**，仅供历史追溯，不作为任何现行结论的依据。
现行文档以项目根目录与 `docs/` 下的版本为准。

## 归档规则

1. 对根目录/`docs/` 文档做**结构性重写**（而非小修小补）之前，先把原件整份复制到本目录；
2. 快照命名：`<原文件名>.<归档日期 YYYY-MM-DD>.md`；
3. 快照内容保持逐字节原样，不做任何修改；
4. 在本文件登记表中补一行说明。
